# Ufolio website

The website for [Ufolio](https://github.com/danxharvard/Ufolio), the little saucer of a browser for Mac.

A single static page (`index.html`, with the app icon in `assets/`). There's no build step and nothing to install.

To publish it with GitHub Pages: **Settings › Pages › Deploy from a branch › `main` / root**.
